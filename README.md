```text
idea -> datos ordenados -> decisiones mejores -> trabajo real
```

## En construccion, no en vitrina

No me interesa hacer software que solo se vea bien en capturas. Me gusta convertir procesos cotidianos en herramientas claras, utiles y listas para usarse desde el primer dia.

- Sistemas de gestion y administracion
- Datos territoriales y trabajo de campo
- Aplicaciones web y experiencias moviles
- Automatizacion, documentacion y seguridad practica

## Mi forma de trabajar

- Primero entiendo el problema y a quien le va a tocar usar el sistema.
- Prefiero datos completos, flujos simples y decisiones que se puedan explicar.
- Cuido los detalles: una buena herramienta debe ser clara, segura y agradable de usar.
- Documento lo importante para que el trabajo no dependa de una sola persona.
